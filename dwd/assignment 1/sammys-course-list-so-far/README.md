# 📚 Sammy's ITP Course Checklist

A simple HTML page that displays the courses I've taken (or am taking) at NYU's ITP program. Styled using custom CSS and the Inter font from Google Fonts.

![Inter Font Badge](https://img.shields.io/badge/font-Inter-blue)

---

## 📖 About

This project is a minimal and clean webpage for keeping track of courses by semester. It uses semantic HTML and custom styling with a linked stylesheet (`styles.css`). It's also a personal experiment in styling, layout, and typography.

The font used is [**Inter**](https://fonts.google.com/specimen/Inter), chosen for its clarity and modern look.

---

## 🔧 Setup

### Prerequisites

- A web browser (Chrome, Firefox, etc.)
- A code editor (e.g., VS Code) if you want to modify the file

### Usage

1. Clone or download the project.
2. Open `index.html` in your browser.
3. You’ll see a list of courses by semester.

---

## 🧪 Tech Stack

- **HTML5**
- **CSS3** (`styles.css`)
- **Google Fonts** - [Inter](https://fonts.google.com/specimen/Inter)

## ✍️ Structure

The page has a single section with two main lists:

- **Semester 2**  
  Courses currently being taken

- **Semester 1**  
  Courses completed during the first semester
