
# 📖 Data of the Bible

**Data of the Bible** is a clean, interactive web project exploring the structure of the Bible through data visualization.

It lets users browse all 66 books via a modern grid or list layout, view quick statistics, and explore insights in a minimalist, responsive design.

---

## ✨ Features

- Interactive Grid and List Views
- Quick Stats (Books, Chapters, Verses, Words)
- Click to view book details in a modal
- Responsive design for all devices
- Lightweight — pure HTML, CSS, JavaScript
- Modern, minimalist aesthetic (inspired by reMarkable.com)

---

## 🚀 Getting Started

- Open `index.html` in your browser
- Toggle between views
- Explore book data and quick questions

---

## 🛠 Built With

- HTML5 + CSS3 (Flexbox, Grid)
- Vanilla JavaScript
- SVG icons for controls
